लाइमलाइट जीरो-कोड रोबोटिक परसेप्शन
लाइमलाइट स्मार्ट कैमरा को रोबोटिक परसेप्शन को यथासंभव आसान और विश्वसनीय बनाने के लिए डिज़ाइन किया गया है, बिना कच्चे प्रदर्शन से समझौता किए। लाइमलाइट प्लेटफॉर्म पूर्ण शुरुआती लोगों के लिए भी आसान है, और पेशेवरों के लिए भी शक्तिशाली है।
अंतर्निहित वेब इंटरफेस का उपयोग करके कलर ब्लॉब्स, एप्रिलटैग्स, न्यूरल नेटवर्क, और अधिक के लिए जीरो-कोड कंप्यूटर विजन पाइपलाइन कॉन्फ़िगर करें।
अंतर्निहित वेब इंटरफेस या विजुअल स्टूडियो कोड का उपयोग करके टेंसरफ्लो, ओपनसीवी, और अधिक के साथ कस्टम पायथन स्नैपस्क्रिप्ट पाइपलाइन लिखें।
लाइमलाइट हार्डवेयर एक उच्च-बैंडविड्थ, अल्ट्रा-लो-लेटेंसी MIPI-CSI इमेजिंग सेंसर, एक ARM64 कंप्यूटर, पावर कंडीशनिंग, और लाइमलाइटOS को एकीकृत करता है।
लाइमलाइटOS REST/HTTP, वेबसॉकेट, मॉडबस, और नेटवर्कटेबल्स प्रोटोकॉल का समर्थन करता है। यह JSON और रॉ आउटपुट फॉर्मेट का समर्थन करता है।
