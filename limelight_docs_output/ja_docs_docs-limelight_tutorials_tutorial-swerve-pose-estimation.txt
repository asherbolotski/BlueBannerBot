Limelight UIでロボットの中心に対するLimelightの位置を設定します。
以下のコードを参照してください。複数のタグが見えている場合にのみ、Limelightの推定値を取り入れています。IMUが正確なロボットの向きを提供できるため、測定された回転の標準偏差を大きな数値に設定しています。
一般的な経路計画ツールがブルーコーナーを常にフィールド原点とする戦略を採用しているため、常にbotpose_wpiblue測定値を読み取ります。
