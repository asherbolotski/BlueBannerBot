Decodificación y Seguimiento de Códigos de Barras
LLOS soporta el seguimiento y decodificación de códigos QR, DataMatrix, UPC, EAN, Code128 y PDF417
Con las Cámaras Inteligentes de la Serie LL3, puedes esperar:
50-60FPS Detección y Decodificación de Múltiples Códigos QR a 1280x800
50-60FPS Detección y Decodificación de Múltiples DataMatrix a 1280x800
30FPS Decodificación de Múltiples UPC, EAN, Code128 y PDF417 a 1280x800
Ten en cuenta lo siguiente:
Las cadenas de datos de códigos de barras se publican en el array "rawbarcodes" de nt.
Los datos de códigos de barras también se publican en el array "Barcode" en la salida de Resultados JSON.
El pipeline de Códigos de Barras completará todas las métricas 2D como tx, ty, ta, tcornxy, etc. en todas las APIs
