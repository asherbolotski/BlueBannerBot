AprilTag मैप विशिष्टता
Limelight का फील्ड-स्पेस लोकलाइजेशन फीचर WPILIB के पोज एस्टिमेटर्स द्वारा उपयोग के लिए रोबोट पोज की गणना करने के लिए .fmap फाइलों का उपयोग करता है।
हमारी fmap फाइलें अलग-अलग टारगेट आकारों और अलग-अलग परिवारों वाले मानचित्रों का समर्थन करती हैं।
आप fmaps का उपयोग "वातावरण" जैसे FRC फील्ड्स, या "वस्तुओं" जैसे कि वस्तुएँ जिनमें कई अटैच्ड AprilTags हैं, को परिभाषित करने के लिए कर सकते हैं।
fmap का उपयोग करने के लिए, आपको बस इंटरफेस या REST अपलोड API का उपयोग करके इसे अपने Limelight पर अपलोड करना होगा।
.fmap फाइल एक JSON फाइल है जिसमें एक "fiducial" ऐरे होता है।
fiducial ऐरे में प्रत्येक एंट्री में निम्नलिखित संरचना होती है:
family
AprilTag/Fiducial परिवार
id
टैग ID
size
टैग का आकार mm में
transform
टारगेट का 4x4 मैट्रिक्स ट्रांसफॉर्म। रो-मेजर, SI इकाइयां।
unique
निर्दिष्ट करता है कि टारगेट इस मैप में अद्वितीय है या कई बार दिखाया गया है
इसके अतिरिक्त, टॉप-लेवल ऑब्जेक्ट में एक "type" स्ट्रिंग होती है जो मैप प्रकार को निर्दिष्ट करती है।
type
फील्ड प्रकार जैसे frc, ftc, ftcd (ftc डायमंड)
