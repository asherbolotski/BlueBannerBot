3D座標系の詳細
Limelightカメラ空間
​
カメラレンズを(0,0,0)とする3D直交座標系。
X+ → 右方向を指す（カメラの視点から）
Y+ → 下方向を指す
Z+ → カメラから外側に向かって指す
ターゲット空間
​
ターゲットの中心を(0,0,0)とする3D直交座標系。
X+ → ターゲットの右側を指す（ターゲットを見ている場合）
Y+ → 下方向を指す
Z+ → ターゲットから外側に向かって指す（ターゲット平面に垂直）
ロボット空間
​
床に投影されたロボットフレームの中心を(0,0,0)とする3D直交座標系。
X+ → 前方を指す（前方ベクトル）
Y+ → ロボットの右側を指す（右ベクトル）
Z+ → 上方向を指す（上ベクトル）
フィールド空間（FTC）
​
フィールドの中心を(0,0,0)とする3D直交座標系
フィールド空間（FTCダイヤモンド）
​
フィールドの中心を(0,0,0)とする3D直交座標系
フィールド空間（FRC）（マップジェネレーターで使用）
​
フィールドの中心を(0,0,0)とする3D直交座標系
X+ → フィールドの長辺に沿って指す
Y+ → フィールドの短辺に沿って上方向を指す
Z+ → 空に向かって指す
右手系。正のシータは外側から見て反時計回りの回転をもたらす
フィールド空間（FRC WPIBlue）（すべてのFRCチームに推奨されるフィールド空間）
​
標準的なFRC座標系と同様ですが、(0,0,0)がブルーアライアンスの原点にあります。
フィールド空間（FRC WPIRed）（使用しないでください）
​
標準的なFRC座標系と同様ですが、(0,0,0)がレッドアライアンスの原点にあり、180度回転しています。
