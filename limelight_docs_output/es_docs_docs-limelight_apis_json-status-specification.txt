Especificación de Estado JSON
La salida de estado JSON de Limelight es útil para información diagnóstica general.
La misma salida de estado JSON puede obtenerse utilizando una de nuestras bibliotecas, o mediante una solicitud GET a (dirección IP):5807/status
Cada objeto de estado JSON contiene las siguientes entradas:
Nombre de Clave
Descripción del Valor
cameraQuat
Cuaternión de la cámara (w, x, y, z)
cid
ID del Sensor de la Cámara
cpu
Uso de CPU (porcentaje)
finalYaw
Valor final de guiñada
fps
Cuadros por segundo
hwType
Entero de tipo de hardware
ignoreNT
Bandera de ignorar NetworkTables
interfaceNeedsRefresh
Bandera de solicitud de actualización de interfaz
name
Nombre del dispositivo / nombre de host
pipeImgCount
Recuento de imágenes de pipeline
pipelineIndex
Índice de pipeline actual
pipelineType
Tipo de pipeline actual
ram
Uso de RAM (porcentaje)
snapshotMode
Bandera de modo instantánea
temp
Temperatura de CPU (Celsius)
