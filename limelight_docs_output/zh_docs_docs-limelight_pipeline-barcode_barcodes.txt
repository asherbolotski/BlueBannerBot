条形码解码和跟踪
LLOS支持QR码、DataMatrix、UPC、EAN、Code128和PDF417码的跟踪和解码
使用LL3系列智能相机，您可以获得：
1280x800分辨率下50-60FPS多QR码检测和解码
1280x800分辨率下50-60FPS多DataMatrix检测和解码
1280x800分辨率下30FPS多UPC、EAN、Code128和PDF417解码
请记住以下几点：
条形码数据字符串会发布到"rawbarcodes" nt数组。
条形码数据也会发布到JSON结果输出中的"Barcode"数组。
条形码管道将在所有API中填充所有2D指标，如tx、ty、ta、tcornxy等
