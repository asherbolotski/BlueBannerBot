Especificação de Status JSON
A saída de status JSON do Limelight é útil para informações gerais de diagnóstico
A mesma saída de status JSON pode ser recuperada usando uma de nossas bibliotecas, ou via solicitação GET em (endereço IP):5807/status
Cada objeto de status JSON contém as seguintes entradas:
Nome da Chave
Descrição do Valor
cameraQuat
Quaternião da câmera (w, x, y, z)
cid
ID do Sensor da Câmera
cpu
Uso da CPU (porcentagem)
finalYaw
Valor final de guinada
fps
Quadros por segundo
hwType
Inteiro do tipo de hardware
ignoreNT
Flag para ignorar NetworkTables
interfaceNeedsRefresh
Flag de solicitação de atualização da interface
name
Nome do dispositivo / hostname
pipeImgCount
Contagem de imagens do pipeline
pipelineIndex
Índice do pipeline atual
pipelineType
Tipo do pipeline atual
ram
Uso de RAM (porcentagem)
snapshotMode
Flag do modo snapshot
temp
Temperatura da CPU (Celsius)
