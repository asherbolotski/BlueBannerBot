Uso
​
Esta é uma biblioteca de arquivo único. Tudo o que você precisa fazer é copiar o arquivo LimelightHelpers.java da versão mais recente (
https://github.com/LimelightVision/limelightlib-wpijava/releases
) para a pasta "robot" do seu projeto Java. Você não precisa criar objetos para seus Limelights - a biblioteca é simples e funcional para maximizar a facilidade de uso e confiabilidade.
Dicas para o Sucesso
​
Comece de forma simples! Muitas equipes de FRC bem-sucedidas usam abordagens básicas de forma eficaz. Por exemplo, a Equipe 2056 em 2024 usou um pipeline de cores padrão de 90FPS em vez de redes neurais para rastreamento de peças do jogo.
Pense sobre o que você realmente precisa: Você precisa de localização completa no campo, ou um simples centramento de alvo funcionaria (por exemplo,
driveSpeed = result.getTx() * 0.03
)?
