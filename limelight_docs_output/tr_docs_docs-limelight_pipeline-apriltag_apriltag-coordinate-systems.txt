3B Koordinat Sistemleri Detaylı
Limelight Kamera Uzayı
​
Kamera lensinde (0,0,0) noktasında bulunan 3B Kartezyen Koordinat Sistemi.
X+ → Sağa doğru işaret eder (kamerayı somutlaştıracak olsaydınız)
Y+ → Aşağıya doğru işaret eder
Z+ → Kameradan dışarı doğru işaret eder
Hedef Uzayı
​
Hedefin merkezinde (0,0,0) noktasında bulunan 3B Kartezyen Koordinat Sistemi.
X+ → Hedefe bakıyorsanız, hedefin sağına doğru işaret eder
Y+ → Aşağıya doğru işaret eder
Z+ → Hedeften dışarı doğru işaret eder (hedefin düzlemine dik).
Robot Uzayı
​
Robot gövdesinin merkezinin zemine izdüşümünde (0,0,0) noktasında bulunan 3B Kartezyen Koordinat Sistemi.
X+ → İleri doğru işaret eder (İleri Vektör)
Y+ → Robotun sağına doğru işaret eder (Sağ Vektör)
Z+ → Yukarı doğru işaret eder (Yukarı Vektör)

Sahanın merkezinde (0,0,0) noktasında bulunan 3B Kartezyen Koordinat Sistemi
Saha Uzayı (FRC) (Harita oluşturucu tarafından kullanılır)
​
Sahanın merkezinde (0,0,0) noktasında bulunan 3B Kartezyen Koordinat Sistemi
X+ → Sahanın uzun kenarı boyunca işaret eder
Y+ → Sahanın kısa kenarı boyunca yukarı doğru işaret eder
Z+ → Gökyüzüne doğru işaret eder
Sağ el kuralı. Pozitif teta, dış perspektiften bakıldığında saatin tersi yönünde dönüşle sonuçlanır
Saha Uzayı (FRC WPIBlue) (Tüm FRC Takımları için Tercih Edilen Saha Uzayı)
​
Standart FRC koordinat sistemi gibidir, ancak (0,0,0) mavi-ittifak başlangıç noktasındadır.
Saha Uzayı (FRC WPIRed) (Bunu kullanmayın)
​
Standart FRC koordinat sistemi gibidir, ancak (0,0,0) kırmızı-ittifak başlangıç noktasındadır ve 180 derece döndürülmüştür.
