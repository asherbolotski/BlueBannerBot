十字准线校准
Limelight的十字准线简化了偏移校准。您无需在代码中存储角度偏移，只需将机器人对准目标，然后点击"校准"即可。
校准十字准线会移动您的目标数据的"零点"。如果您的Limelight没有完美地安装在机器人的中心位置，这个功能非常有用。
单十字准线模式
​
将您的机器人放置在理想的得分位置和旋转角度，然后点击"校准"。现在，tx和ty值为"零"就等同于机器人完美对准。如果您的机器人需要为新场地重新校准，只需在练习赛中找到机器人的完美对准位置，并在比赛期间点击"校准"。
双十字准线模式
​
想象一个带有偏轴摄像头或发射器的机器人，需要从场地上的多个位置向目标发射游戏物体。当机器人接近目标时，其十字准线必须实时调整以进行补偿。双十字准线模式就是为这种功能而设计的。将您的机器人放置在最近的得分位置和旋转角度，校准十字准线"A"。将您的机器人放置在最远的得分位置和旋转角度，校准十字准线"B"。当您在双十字准线模式下校准时，十字准线还会存储一个面积值。您会注意到，当机器人在最小和最大得分距离之间移动时，十字准线会在十字准线"A"和十字准线"B"之间移动。这是通过检查目标的面积，并将其与校准期间看到的两个目标面积进行比较来实现的。
