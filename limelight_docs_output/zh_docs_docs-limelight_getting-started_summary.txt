Limelight 零代码机器人感知
Limelight智能相机的设计目的是使机器人感知尽可能简单可靠，同时不牺牲原始性能。Limelight平台对完全初学者来说足够简单，对专业人士来说又足够强大。
使用内置的网页界面配置零代码计算机视觉管道，用于颜色斑点、AprilTags、神经网络等。
使用内置的网页界面或Visual Studio Code编写带有tensorflow、opencv等的自定义Python SnapScript管道。
Limelight硬件集成了高带宽、超低延迟的MIPI-CSI成像传感器、ARM64计算机、电源调节和LimelightOS。
LimelightOS支持REST/HTTP、Websocket、Modbus和NetworkTables协议。它支持JSON和原始输出格式。
