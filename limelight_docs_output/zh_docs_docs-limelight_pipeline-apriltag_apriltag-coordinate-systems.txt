3D坐标系统详解
Limelight相机空间
​
以相机镜头为(0,0,0)的3D笛卡尔坐标系。
X+ → 指向右侧（如果你站在相机的位置）
Y+ → 指向下方
Z+ → 指向相机外
目标空间
​
以目标中心为(0,0,0)的3D笛卡尔坐标系。
X+ → 指向目标的右侧（当你面对目标时）
Y+ → 指向下方
Z+ → 指向目标外（垂直于目标平面）
机器人空间
​
以机器人框架中心投影到地面的点为(0,0,0)的3D笛卡尔坐标系。
X+ → 指向前方（前向量）
Y+ → 指向机器人的右侧（右向量）
Z+ → 指向上方（上向量）
场地空间（FTC）
​
以场地中心为(0,0,0)的3D笛卡尔坐标系
场地空间（FTC钻石形）
​
以场地中心为(0,0,0)的3D笛卡尔坐标系
场地空间（FRC）（地图生成器使用）
​
以场地中心为(0,0,0)的3D笛卡尔坐标系
X+ → 指向场地长边方向
Y+ → 指向场地短边方向
Z+ → 指向天空
右手系。从外部正视角度看，正theta值导致逆时针旋转
场地空间（FRC WPIBlue）（所有FRC团队的首选场地空间）
​
与标准FRC坐标系相同，但(0,0,0)位于蓝方联盟原点。
场地空间（FRC WPIRed）（不建议使用）
​
与标准FRC坐标系相同，但(0,0,0)位于红方联盟原点，并旋转180度。
