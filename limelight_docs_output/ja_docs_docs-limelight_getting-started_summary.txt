Limelight ゼロコードロボット認識
Limelight スマートカメラは、生のパフォーマンスを犠牲にすることなく、ロボット認識をできるだけ簡単かつ信頼性の高いものにするために設計されました。Limelightプラットフォームは完全な初心者でも簡単に使え、プロフェッショナルにも十分な性能を持っています。
内蔵のウェブインターフェースを使用して、カラーブロブ、AprilTag、ニューラルネットワークなどのゼロコードコンピュータビジョンパイプラインを設定できます。
内蔵のウェブインターフェースまたはVisual Studio Codeを使用して、tensorflow、opencvなどを使用したカスタムPython SnapScriptパイプラインを作成できます。
Limelightハードウェアは、高帯域幅、超低遅延のMIPI-CSIイメージングセンサー、ARM64コンピュータ、電源調整、およびLimelightOSを統合しています。
LimelightOSは、REST/HTTP、Websocket、Modbus、およびNetworkTablesプロトコルをサポートしています。JSONおよび生の出力形式をサポートしています。
