מערכת תפיסה רובוטית ללא קוד של Limelight
מצלמת Limelight החכמה תוכננה כדי להפוך את תפיסת הרובוטיקה לקלה ואמינה ככל האפשר מבלי להתפשר על ביצועים גולמיים. פלטפורמת Limelight קלה מספיק למתחילים לגמרי, וחזקה מספיק למקצוענים.
הגדר צינורות ראייה ממוחשבת ללא קוד עבור כתמי צבע, תגי AprilTag, רשתות נוירונים ועוד באמצעות ממשק האינטרנט המובנה.
כתוב צינורות SnapScript מותאמים אישית בפייתון עם tensorflow, opencv ועוד באמצעות ממשק האינטרנט המובנה או Visual Studio Code.
חומרת Limelight משלבת חיישן הדמיה MIPI-CSI ברוחב פס גבוה ובהשהיה נמוכה במיוחד, מחשב ARM64, ייצוב מתח ו-LimelightOS.
LimelightOS תומכת בפרוטוקולי REST/HTTP, Websocket, Modbus ו-NetworkTables. היא תומכת בפורמטי פלט JSON ופלט גולמי.
