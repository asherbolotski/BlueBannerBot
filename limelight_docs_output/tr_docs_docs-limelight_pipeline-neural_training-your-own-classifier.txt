Özel Sınıflandırıcı Model Eğitimi
Google'ın Teachable Machine'i, kullanıcıların herhangi bir kod veya ileri düzey makine öğrenimi bilgisi olmadan sınıflandırıcı modeller oluşturmasına olanak tanıyan tarayıcı tabanlı bir araçtır.
Veri Toplama
​
Tanımak istediğiniz her sınıf için görüntüler toplayın.
Dengeli bir veri setine sahip olduğunuzdan emin olun (her sınıf için yaklaşık olarak eşit sayıda görüntü).
Kamera açısı, aydınlatma, arka planlar, nesne özellikleri vb. konularda çeşitlilik sağladığınızdan emin olun.
Teachable Machine ile Eğitim
​
Teachable Machine web sitesine gidin:
teachable machine
"Get Started" (Başla) düğmesine tıklayın.
Bir görüntü sınıflandırıcısı oluşturmak için "Image Project" (Görüntü Projesi) seçeneğini seçin.
"Standard image model" (Standart görüntü modeli) seçeneğini seçin.
Her sınıf için:
'Add Class' (Sınıf Ekle) düğmesine tıklayın.
O sınıfa ait görüntüleri yükleyin.
Tüm sınıfları ekledikten sonra "Train Model" (Modeli Eğit) düğmesine tıklayın.
Eğitim tamamlandıktan sonra, modeli doğrudan tarayıcıda test edebilirsiniz.
"Export Model" (Modeli Dışa Aktar) düğmesine tıklayın.
"Tensorflow Lite" sekmesine gidin.
Limelight Google Coral kullanıyorsanız "EdgeTPU" seçeneğini seçin.
FTC için Limelight 3A kullanıyorsanız veya CPU Sinir Ağı işlevselliği kullanıyorsanız "Quantized" (Nicelleştirilmiş) seçeneğini seçin.
Modeli indirin.
