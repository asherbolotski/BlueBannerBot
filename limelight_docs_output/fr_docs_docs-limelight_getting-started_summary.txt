Limelight Perception Robotique Sans Code
La caméra intelligente Limelight a été conçue pour rendre la perception robotique aussi facile et fiable que possible sans sacrifier les performances brutes. La plateforme Limelight est suffisamment simple pour les débutants complets, et suffisamment puissante pour les professionnels.
Configurez des pipelines de vision par ordinateur sans code pour les taches de couleur, les AprilTags, les réseaux de neurones et plus encore à l'aide de l'interface web intégrée.
Écrivez des pipelines Python SnapScript personnalisés avec tensorflow, opencv et plus encore en utilisant l'interface web intégrée ou Visual Studio Code.
Le matériel Limelight intègre un capteur d'imagerie MIPI-CSI à haute bande passante et à latence ultra-faible, un ordinateur ARM64, un conditionnement d'alimentation et LimelightOS.
LimelightOS prend en charge les protocoles REST/HTTP, Websocket, Modbus et NetworkTables. Il supporte les formats de sortie JSON et bruts.
