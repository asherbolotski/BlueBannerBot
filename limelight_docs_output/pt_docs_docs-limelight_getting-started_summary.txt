Limelight Percepção Robótica Sem Código
A Câmera Inteligente Limelight foi projetada para tornar a percepção robótica o mais fácil e confiável possível sem sacrificar o desempenho bruto. A plataforma Limelight é simples o suficiente para iniciantes completos e poderosa o suficiente para profissionais.
Configure pipelines de visão computacional sem código para manchas coloridas, AprilTags, redes neurais e mais usando a interface web integrada.
Escreva pipelines personalizados em Python SnapScript com tensorflow, opencv e mais usando a interface web integrada ou Visual Studio Code.
O hardware Limelight integra um sensor de imagem MIPI-CSI de alta largura de banda e ultrabaixa latência, um computador ARM64, condicionamento de energia e LimelightOS.
O LimelightOS suporta protocolos REST/HTTP, Websocket, Modbus e NetworkTables. Suporta formatos de saída JSON e raw.
