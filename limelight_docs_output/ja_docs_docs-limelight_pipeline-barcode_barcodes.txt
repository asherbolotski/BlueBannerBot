バーコードのデコードとトラッキング
LLOSはQRコード、DataMatrix、UPC、EAN、Code128、およびPDF417コードのトラッキングとデコードをサポートしています
LL3シリーズのスマートカメラでは、以下のパフォーマンスが期待できます：
1280x800解像度で50-60FPSの複数QRコード検出とデコード
1280x800解像度で50-60FPSの複数DataMatrix検出とデコード
1280x800解像度で30FPSの複数UPC、EAN、Code128、およびPDF417デコード
以下の点に注意してください：
バーコードデータ文字列は「rawbarcodes」nt配列に投稿されます。
バーコードデータはJSON結果出力の「Barcode」配列にも投稿されます。
バーコードパイプラインは、すべてのAPIにわたってtx、ty、ta、tcornxyなどのすべての2Dメトリクスを入力します
