Localisation avec MegaTag
Assurez-vous qu'une carte de terrain est téléchargée dans votre Limelight.
Configurez le pipeline 0 comme un Pipeline Apriltag et activez la fonctionnalité 3D
Configurez la pose de votre Limelight par rapport au centre de votre robot dans l'interface utilisateur Limelight
Consultez le code ci-dessous. Nous n'intégrons les estimations de Limelight que lorsque plus d'un tag est visible. Nous définissons l'écart-type de la rotation mesurée à un nombre élevé
car nous pouvons faire confiance à notre IMU pour nous donner le bon cap du robot.
Nous lisons toujours la mesure botpose_wpiblue car les outils courants de planification de trajectoire ont adopté une stratégie d'origine de terrain toujours dans le coin bleu.
Utilisez megatag 2 si possible.
