Robot Deep Space 2019
El juego FRC 2019 Deep Space tenía objetivos de visión sobre muchas de las metas.
A continuación, puedes encontrar programas de ejemplo completos en Java y Labview que implementan un método simple para
conducir automáticamente hacia una meta en Deep Space.
Estos son programas muy simples y solo están destinados a mostrar el concepto de usar datos de seguimiento de limelight para controlar tu robot.
En cada programa, puedes conducir tu robot con un gamepad.
Si mantienes presionado el botón 'A', y el limelight ve un objetivo válido
(dependiendo de la configuración en tu pipeline), entonces el robot conducirá automáticamente hacia el objetivo.
Ten cuidado de ajustar las diversas constantes en el código para tu robot en particular.
Algunos robots giran o conducen más fácilmente que otros, por lo que el ajuste de las constantes de control proporcional debe hacerse caso por caso.
Asegúrate de que el robot conduzca correctamente usando el controlador gamepad antes de habilitar el comportamiento de búsqueda de limelight.
