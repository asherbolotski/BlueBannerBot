Limelight Percepción Robótica Sin Código
La Cámara Inteligente Limelight fue diseñada para hacer la percepción robótica lo más fácil y confiable posible sin sacrificar el rendimiento bruto. La plataforma Limelight es lo suficientemente fácil para principiantes completos, y lo suficientemente potente para profesionales.
Configure pipelines de visión por computadora sin código para manchas de color, AprilTags, redes neuronales y más utilizando la interfaz web incorporada.
Escriba pipelines personalizados de Python SnapScript con tensorflow, opencv y más usando la interfaz web incorporada o Visual Studio Code.
El hardware Limelight integra un sensor de imagen MIPI-CSI de alto ancho de banda y latencia ultra baja, una computadora ARM64, acondicionamiento de energía y LimelightOS.
LimelightOS soporta protocolos REST/HTTP, Websocket, Modbus y NetworkTables. Admite formatos de salida JSON y raw.
