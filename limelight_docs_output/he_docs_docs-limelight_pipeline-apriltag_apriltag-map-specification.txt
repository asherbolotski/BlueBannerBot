מפרט מפת AprilTag
תכונת המיקום במרחב-שדה של Limelight משתמשת בקבצי .fmap כדי לחשב את תנוחת הרובוט לשימוש על ידי מעריכי התנוחה של WPILIB.
קבצי ה-fmap שלנו תומכים במפות המורכבות ממטרות בגדלים שונים ומשפחות שונות.
ניתן להשתמש ב-fmap כדי להגדיר "סביבות" כמו שדות FRC, או "אובייקטים" כמו חפצים שיש להם מספר תגי AprilTag מחוברים.
כדי להשתמש ב-fmap, כל מה שצריך לעשות הוא להעלות אותו ל-Limelight שלך באמצעות הממשק או ה-REST upload API
קובץ ה-.fmap הוא קובץ JSON המכיל מערך "fiducial" יחיד.
כל רשומה במערך fiducial כוללת את המבנה הבא:
family
משפחת AprilTag/Fiducial
id
מזהה התג
size
גודל התג במ"מ
transform
מטריצת טרנספורמציה 4x4 של המטרה. סדר שורות, יחידות SI.
unique
מציין האם המטרה היא ייחודית במפה זו או מופיעה מספר פעמים
בנוסף, האובייקט ברמה העליונה כולל מחרוזת "type" המציינת את סוג המפה.
type
סוג השדה, למשל frc, ftc, ftcd (יהלום ftc)
