AprilTagマップ仕様
Limelightのフィールド空間ローカライゼーション機能は、.fmapファイルを使用してWPILIBのポーズ推定器で使用するロボットポーズを計算します。
fmapファイルは、異なるターゲットサイズと異なるファミリーで構成されるマップをサポートしています。
fmapを使用して、FRCフィールドなどの「環境」や、複数のAprilTagが取り付けられたオブジェクトなどの「オブジェクト」を定義できます。
fmapを使用するには、インターフェースまたはRESTアップロードAPIを使用してLimelightにアップロードするだけです。
.fmapファイルは、単一の「fiducial」配列を含むJSONファイルです。
fiducial配列の各エントリは、以下の構造を持っています：
family
AprilTag/Fiducialファミリー
id
タグID
size
タグサイズ（mm）
transform
ターゲットの4x4行列変換。行優先、SI単位。
unique
ターゲットがこのマップ内で一意であるか、複数回使用されているかを指定
さらに、トップレベルのオブジェクトには、マップタイプを指定する「type」文字列があります。
type
フィールドタイプ（例：frc、ftc、ftcd（ftcダイヤモンド））
