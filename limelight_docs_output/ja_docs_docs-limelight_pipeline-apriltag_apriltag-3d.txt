3D AprilTags
Limelight OSには、3つのレベルの3D AprilTagトラッキングがあります：
注目点トラッキング（使いやすく、コード変更が不要で、「tx」と「ty」と互換性あり）
完全3Dトラッキング
ロボット位置推定
注目点トラッキング
​
注目点トラッキングでは、AprilTagに対して相対的な3D注目点を定義することができます。
例えば、AprilTagの左6インチ、後ろ2インチにあるフィールド上の特徴を狙いたい場合。ウェブインターフェースでその注目点を（メートル単位で）簡単に定義し、実際の現実世界のターゲットであるかのようにtxとtyを使ってこの3D点を追跡することができます。
完全3Dトラッキング
​
「Advanced」タブの「visualizer」セクションでは、各変換の目的を理解するのに役立つ複数のビジュアライザーが見つかります。一般的に、最も役立つ変換は「Camera Transform in Target Space」（ターゲット空間内のカメラ変換）、「Robot Transform in Target Space」（ターゲット空間内のロボット変換）、および「Robot Transform in Field Space」（フィールド空間内のロボット変換）です。詳細については座標系のドキュメントを参照してください。
