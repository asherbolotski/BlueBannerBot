Limelight 3A is a plug and play, zero-code perception system for FIRST Tech Challenge Teams. Based on the battle-tested Limelight 3 for FRC, it brings high performance AprilTag tracking, game piece tracking, and full-field robot localization to teams of all experience levels.
*The REV Control Hub can only support a single LL3A at this time.*
Hardware Features:
All-Aluminum Enclosure
Anti-Reflective Gorilla Glass Lens Cover
REV and GoBilda Threaded Mounting
USB-C Flash and Communication Port
Quad-core Cortex-A72 @ 1.5GHz
90FPS Capture @ 640x480, and up to 60FPS Capture @1280x960
Color, Rolling Shutter
Software Features:
Browser-based configuration interface
Point-and-click pipeline tuning
Optional Python Programming interface
Full 3D Field Visualizer
Full FTC SDK Integration
Zero-Code Colored object tracking at 90FPS
Zero-Code Full-Field AprilTag Tracking
Zero-Code MegaTag1 Multi-Tag Robot Localization Algorithm
IMU-Fused MegaTag2 Robot Localization Algorithm
Custom Python SnapScript Pipelines
Image classification and Object Detection Neural Networks
Open-source Neural Network Training Pipelines
Built-In Camera Calibration Pipeline
Full 3D AprilTag Map Editor
