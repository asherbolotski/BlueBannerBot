使用MegaTag进行定位
确保已将场地地图上传到您的Limelight。
将管道0配置为Apriltag管道并启用3D功能。
在Limelight UI中配置Limelight相对于机器人中心的位姿。
参考下面的代码。我们只在可见多个标签时采用Limelight的估计。我们将测量旋转的标准差设置为一个较大的数值，因为我们可以信任IMU提供正确的机器人朝向。
我们始终读取botpose_wpiblue测量值，因为常用的路径规划工具采用了蓝色角落作为场地原点的策略。
如果可能，请使用megatag 2。
