רובוט 2019 Deep Space
משחק ה-FRC לשנת 2019 Deep Space כלל מטרות ראייה מעל רבים מהיעדים.
להלן תוכלו למצוא תוכניות דוגמה מלאות בג'אווה ו-Labview המיישמות שיטה פשוטה לנסיעה אוטומטית
לעבר יעד ב-Deep Space.
אלו הן תוכניות פשוטות מאוד שנועדו להדגים את הרעיון של שימוש בנתוני מעקב של limelight לשליטה ברובוט שלכם.
בכל תוכנית, תוכלו לנהוג ברובוט שלכם עם גיימפאד.
אם תחזיקו את כפתור 'A' לחוץ, וה-limelight רואה מטרה תקפה
(בהתאם להגדרות בצינור העיבוד שלכם) אז הרובוט ייסע אוטומטית לעבר המטרה.
הקפידו לכוונן את הקבועים השונים בקוד עבור הרובוט הספציפי שלכם.
חלק מהרובוטים מסתובבים או נוסעים בקלות יותר מאחרים, לכן כיוון קבועי הבקרה הפרופורציונלית חייב להיעשות על בסיס פרטני.
ודאו שהרובוט נוסע כראוי באמצעות בקר הגיימפאד לפני שתפעילו את התנהגות החיפוש של ה-limelight.
