Limelight Sıfır-Kod Robotik Algılama
Limelight Akıllı Kamera, ham performanstan ödün vermeden robotik algılamayı mümkün olduğunca kolay ve güvenilir hale getirmek için tasarlanmıştır. Limelight platformu tam başlangıç seviyesindekiler için yeterince kolay ve profesyoneller için yeterince güçlüdür.
Yerleşik web arayüzünü kullanarak renk lekeleri, AprilTag'ler, sinir ağları ve daha fazlası için sıfır-kod bilgisayarlı görü işlem hatları yapılandırın.
Yerleşik web arayüzünü veya Visual Studio Code'u kullanarak tensorflow, opencv ve daha fazlasıyla özel Python SnapScript işlem hatları yazın.
Limelight donanımı, yüksek bant genişliğine sahip, ultra düşük gecikmeli MIPI-CSI görüntüleme sensörü, ARM64 bilgisayar, güç düzenleme ve LimelightOS'u entegre eder.
LimelightOS, REST/HTTP, Websocket, Modbus ve NetworkTables protokollerini destekler. JSON ve ham çıktı formatlarını destekler.
