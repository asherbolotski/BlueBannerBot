Metodlar
​
REST-tabanlı
​
get_results()
: HTTP GET ile en son sonuçları getirir.
capture_snapshot(snapname)
: Belirli bir isimle anlık görüntü yakalar.
upload_snapshot(snapname, image_path)
: Belirli bir isim ve görüntü dosyasıyla anlık görüntü yükler.
snapshot_manifest()
: HTTP GET ile anlık görüntü manifestosunu getirir.
delete_snapshots()
: HTTP GET ile tüm anlık görüntüleri siler.
upload_neural_network(nn_type, file_path)
: Belirtilen türde bir sinir ağı dosyası yükler.
hw_report()
: HTTP GET ile donanım raporunu getirir.
cal_default()
: HTTP GET ile varsayılan kalibrasyon verilerini getirir.
cal_file()
: HTTP GET ile dosyadan kalibrasyon verilerini getirir.
cal_eeprom()
: HTTP GET ile EEPROM'dan kalibrasyon verilerini getirir.
cal_latest()
: HTTP GET ile en son kalibrasyon verilerini getirir.
update_cal_eeprom(cal_data)
: HTTP POST ile EEPROM'daki kalibrasyon verilerini günceller.
update_cal_file(cal_data)
: HTTP POST ile dosyadaki kalibrasyon verilerini günceller.
delete_cal_latest()
: HTTP DELETE ile en son kalibrasyon verilerini siler.
delete_cal_eeprom()
: HTTP DELETE ile EEPROM'daki kalibrasyon verilerini siler.
delete_cal_file()
: HTTP DELETE ile dosyadaki kalibrasyon verilerini siler.
Websocket-tabanlı
​
enable_websocket()
: Başka bir thread'de WebSocket bağlantısını başlatır ve başlatır.
disable_websocket()
: WebSocket bağlantısını kapatır ve thread'i birleştirir.
get_latest_results()
: WebSocket'ten alınan en son sonuçları döndürür.
Ayrıştırma
​
limelightresults.parse_results()
: Sonuçları ayrıştırır ve bir GeneralResult nesnesi döndürür
