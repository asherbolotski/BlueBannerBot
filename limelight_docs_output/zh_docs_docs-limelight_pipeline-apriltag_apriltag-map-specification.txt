AprilTag 地图规范
Limelight 的场地空间定位功能使用 .fmap 文件来计算机器人姿态，供 WPILIB 的姿态估计器使用。
我们的 fmap 文件支持由不同目标尺寸和不同标签族组成的地图。
您可以使用 fmap 定义"环境"，如 FRC 场地，或"物体"，如附有多个 AprilTag 的物体。
要使用 fmap，您只需使用界面或 REST 上传 API 将其上传到您的 Limelight 即可。
.fmap 文件是一个包含单个"fiducial"数组的 JSON 文件。
fiducial 数组中的每个条目具有以下结构：
family
AprilTag/基准标记族
id
标签 ID
size
标签尺寸，单位为毫米
transform
目标的 4x4 矩阵变换。行优先，国际单位制。
unique
指定目标在此地图中是唯一的还是多次出现
此外，顶层对象有一个指定地图类型的"type"字符串。
type
场地类型，例如 frc、ftc、ftcd（ftc 钻石）
