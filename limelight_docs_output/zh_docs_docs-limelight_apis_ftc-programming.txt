成功技巧
​
先做简单的事情。在FRC中，我们了解到最优秀的软件团队通常使用最简单的方法。例如，FRC 2056队在2024年使用标准的90FPS颜色管道而不是神经网络来跟踪比赛物品。
以下是开始编程时可以问的问题类型示例：在遥控操作中，你是否需要知道机器人在场地上的位置，或者你只需要平移直到你的十字准星对准特定标签（平移速度 = result.getTx()*.03）？

2. 管道管理
​
管道就像小型的、可即时切换的程序，它们改变Limelight观察世界的方式。你可以在Limelight网页界面中设置10个不同的管道，每个用于不同的任务。以下是如何在它们之间切换：

.
pipelineSwitch
(
0
)
;
// 切换到管道编号0
这是一个发送后不等待的命令。Limelight将在几毫秒内更改其管道，但你的代码不会等待此操作完成就继续执行。如果你想检查当前的管道索引，调用
result.getPipelineIndex()
查看下一节了解如何获取LLResult对象。
