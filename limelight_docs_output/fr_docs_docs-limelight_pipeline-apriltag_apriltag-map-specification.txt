Spécification de carte AprilTag
La fonctionnalité de localisation dans l'espace de terrain de Limelight utilise des fichiers .fmap pour calculer la pose d'un robot à utiliser par les estimateurs de pose de WPILIB.
Nos fichiers fmap prennent en charge des cartes comprenant différentes tailles de cibles et différentes familles.
Vous pouvez utiliser les fmaps pour définir des "environnements" tels que les terrains FRC, ou des "objets" tels que des objets qui ont plusieurs AprilTags attachés.
Pour utiliser un fmap, il vous suffit de le télécharger sur votre Limelight en utilisant l'interface ou l'API REST de téléchargement.
Le fichier .fmap est un fichier JSON contenant un seul tableau "fiducial".
Chaque entrée dans le tableau fiducial a la structure suivante :
family
Famille AprilTag/Fiducial
id
ID du tag
size
Taille du tag en mm
transform
Matrice de transformation 4x4 de la cible. Ordre des lignes, unités SI.
unique
Spécifie si la cible est unique dans cette carte ou présente plusieurs fois
De plus, l'objet de premier niveau a une chaîne "type" spécifiant le type de carte.
type
Type de terrain, par exemple frc, ftc, ftcd (ftc diamond)
