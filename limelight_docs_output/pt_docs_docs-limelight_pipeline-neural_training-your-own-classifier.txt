Treinando um Modelo Classificador Personalizado
O Teachable Machine do Google é uma ferramenta baseada em navegador que permite aos usuários criar modelos classificadores sem nenhum código ou compreensão avançada de aprendizado de máquina.
Coleta de Dados
​
Reúna imagens para cada classe que você deseja reconhecer.
Certifique-se de ter um conjunto de dados equilibrado (um número aproximadamente igual de imagens para cada classe).
Garanta diversidade no ângulo da câmera, iluminação, fundos, características do objeto, etc.
Treinamento com o Teachable Machine
​
Acesse o site do Teachable Machine:
teachable machine
Clique no botão "Get Started" (Começar).
Selecione "Image Project" (Projeto de Imagem) para criar um classificador de imagens.
Selecione "Standard image model" (Modelo de imagem padrão)
Para cada classe:
Clique no botão 'Add Class' (Adicionar Classe).
Faça o upload das imagens pertencentes a essa classe.
Depois de adicionar todas as classes, clique no botão "Train Model" (Treinar Modelo).
Quando o treinamento estiver concluído, você pode testar o modelo diretamente no navegador.
Clique no botão "Export Model" (Exportar Modelo)
Navegue até a aba "Tensorflow Lite"
Selecione "EdgeTPU" se você tiver um Limelight Google Coral
Selecione "Quantized" se estiver usando um Limelight 3A para FTC ou se estiver usando a funcionalidade de Rede Neural CPU.
Baixe o modelo.
